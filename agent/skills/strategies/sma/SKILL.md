# Moving Average Trading Strategy Skill

## Purpose

Use this skill to execute the moving average trading strategy described in the source content.

The strategy uses moving averages to:

- Identify the trend.
- Identify the area of value.
- Time entries using price rejection, trendline breaks, or lower-timeframe break of structure.
- Exit at major swing points or Fibonacci extensions.

Do not use this strategy in a range market.

sell if close M5 is below 100 SMA
buy if close M5 is above 100 SMA
